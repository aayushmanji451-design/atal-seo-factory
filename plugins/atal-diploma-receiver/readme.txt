=== Atal Diploma Receiver ===
Contributors: atal-institute
Requires at least: 6.9
Requires PHP: 8.1
Stable tag: 0.5.0-dev

DEVELOPMENT build for Task 05. It retains the authenticated receiver and adds
native AIOSEO metadata plus deterministic local WebP artwork with exact snapshot
rollback and idempotent SHA-256 reuse for the approved Diploma staging fixture.

The receiver accepts only authenticated drafts and returns bounded canary
verification evidence for the approved one-post flow. This build performs no
AI, paid image API calls, public publishing, scheduling, or bulk work.
It must not be treated as a final release.
